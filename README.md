# delete-discord

自分のDiscord発言を一括削除する個人用ツール(Android向け)。

> ⚠️ ユーザートークンを使う自動操作はDiscord利用規約(セルフボット禁止)に抵触し、アカウント停止のリスクがあります。自己責任で、少量・低頻度で使ってください。

## 構成
- `android/` — Androidアプリ本体(Kotlin / Jetpack Compose、アプリID `com.dcleaner.app`。v2.0以前の `com.example.discordcleaner` とは別アプリ)
- `userscript/` — Tampermonkey版(`.user.js`)と単体HTML版
- `tools/` — 旧CLI版、APKのバージョン読み取りツール
- `releases/` — 署名済みAPK
- `.github/workflows/` — APKのビルド・署名・リリース

## 機能(v2)
- **複数アカウント**: 上部のチップから切り替え。ログイン情報は端末内に暗号化して保存
- **削除**: 対象(サーバー/DM/すべて)→ 条件(◯日より古い・日付・キーワード・添付/リンク・ピン留めを残す)→ 件数を確認 → 古い順に削除
- **ルーチン**: よく使う条件を保存してワンタップ実行
- **スケジュール**: 毎日/毎週/毎月+時刻(前後30分ずらす)、Wi-Fi・充電中・電池残量の条件、1回の上限件数
- **バックグラウンド実行**: 画面を閉じても通知に進捗と停止ボタン。完了・ログイン切れを通知
- **自動更新**: 起動時に新しいバージョンを確認

## 署名キーについて
`discord_cleaner_keystore.jks`(alias `cleaner`)は**リポジトリに含めません**(.gitignore)。
別途安全に保管してください。同じキーで署名し versionCode を上げれば、アンインストールせず更新でき、ログイン(2段階認証)が保持されます。紛失すると再インストール+再ログインが必要です。
